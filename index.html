把模糊的 AI 能力做成能被人稳定用起来的产品。

投放素材生产依赖人工与外部代理，跨内容、投放、代理三方协作，单张周期 2-3 天；直接应用生图大模型则面临 AI 错字、品牌资产失控、渠道合规不过的硬伤，无法满足效果广告「逐字准确、逐版位合规」的投放级要求。

产品动作

  • 人机协同渲染架构：设计「生图模型出场景底图 + 本地渲染引擎叠加文字 / Logo / 装饰」的确定性方案，从架构上保证文案逐字一致
  • 规则工程化：主导将 79 条渠道版位规范、违禁词库、花字排版与元素贴边等设计规范结构化为 JSON 规则引擎，作为 Skill 约束 Agent 的不确定性；建立「生成效果图 → 业务方确认 → 策略沉淀」迭代闭环
  • 素材情报 Agent：从 0 到 1 搭建竞品采集 Agent，自动抓取腾讯妙思、抖音等多平台近 7 天曝光 TOP200 素材并结构化入库，反哺 RAG 素材知识库
  • 多版位策略编排：按信息流 / 应用商店 / 学习机三类用途自动推导差异化规则（CTA 策略、构图结构、多图叙事框架），血缘机制追踪每次迭代的版本谱系，支撑投后复盘归因

项目收益

  • 单张投放级素材交付周期从 2-3 天压缩至 5 分钟，人力环节仅剩策略与终审两个节点
  • 素材审核通过率达 90%，单张平均返工次数保持在 3 次以内
  • 产出可复用 Skill 矩阵与 500+ 条竞品案例库，通过内部 AI 教学分享推广至投放与内容团队，成为团队标准生产工具

视觉陈列从方案设计到落地施工依赖人工驱动：设计师建模出图慢，方案定稿后需人工拆解为木工、油漆、GC 部门各自的执行需求，沟通链条长、返工率高。

产品动作

  • 多 Agent 编排：设计「素材收集 Agent — 效果图生成 Skill — 施工拆解 Agent」三段式流水线，定稿方案自动拆分为木工展台尺寸、油漆色值、GC 部门海报规格等可执行清单
  • 跨工种交付标准化：将各工种既有交付规范前置为 Agent 输出 Schema，AI 产出零二次加工直达施工环节，覆盖 4 个门店陈列项目
  • 方案比选提效：效果图生成 Agent（Coze / Dify）支持方案产出，将陈列师从重复建模中释放，聚焦方案决策与审美把控
  • 评测集构建：基于历史已验收陈列方案构建黄金评测集，定义结构还原度、品牌一致性、施工可落地性三维评分 Rubric，低分样本回流提示词调优

项目收益

  • 方案到施工落地周期缩短 60%，实现「定稿即开工」
  • 陈列师人均方案产出量提升 3 倍，方案比选周期从 2 周缩至 2 天
  • 跨工种沟通返工减少 50%，AI 拆解清单的施工一次性通过率显著提升
